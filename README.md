# Kalkulator zadaszenia — wersja publiczna

Jedna statyczna strona (`index.html`), bez zaplecza, bez cen i bez zamawiania.
Liczy, ile płyt poliwęglanowych, profili, taśm i krepeżu potrzeba na zadaszenie
o podanych wymiarach.

Adres: https://exborboss.github.io/kalkulator-zadaszenia-www/

Kod źródłowy i generator strony są w prywatnym repozytorium
`exborboss/kalkulator-zadaszenia`. Tutaj leży wyłącznie zbudowany plik,
żeby adres był publicznie osiągalny.
